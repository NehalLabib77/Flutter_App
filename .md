EduCompass প্রথমে TF-IDF ব্যবহার করে course title, skills, subject, description এবং অন্যান্য metadata-কে numerical vectors-এ convert করে। User query বা preference-ও একই TF-IDF feature space-এ convert হয় এবং content similarity বের করা হয়। এরপর system user preferences, previous behavior such as favorite/enroll/complete, course quality এবং popularity score-এর সাথে TF-IDF similarity combine করে একটি final hybrid score তৈরি করে। সেই score অনুযায়ী courses rank করে Flutter app-এ recommendation দেখানো হয়।

* Render deployment
I deployed my Flask backend on Render by connecting my GitHub repository and selecting the educompass branch. Render installs the dependencies from backend/requirements.txt and starts the Flask application using Gunicorn through backend/run.py. The trained TF-IDF artifacts are stored under ml/artifacts/models/v4, which the backend loads at startup. PostgreSQL, Firebase credentials, JWT secrets, and SSLCOMMERZ sandbox credentials are configured using Render environment variables. Finally, the Flutter application connects to the deployed API using https://educompass-api.onrender.com from api_config.dart.
